# 对外部署与访问控制（v0.4 第 5 项）

本文说明如何把当前本机试用版挂到可被企业官网引用的 HTTPS 地址，并配置来源白名单、可信代理与后台防护。  
**未提供真实域名与证书前，不能完成公网嵌入联调；本地测试通过不能代替生产验收。**

## 1. 架构建议

```text
访客浏览器
  └─ 企业官网 (https://www.example.com)  加载 widget.js
        └─ iframe → 客服站点 (https://support.example.com/chat)
              └─ /api → backend（仅内网可达）
```

- `web`（或外层 Nginx/Caddy）对外提供静态页与 `/api` 反代。
- `backend` / `db` / `redis` **不要**对公网直接暴露端口。
- Cookie 仅在客服站点自身域名下使用；访客会话凭据在 iframe 内，不依赖第三方 Cookie。

## 2. 环境变量（占位，勿提交真实密钥）

在 `.env` 中配置（参考 `.env.example`）：

| 变量 | 说明 |
| --- | --- |
| `PUBLIC_ORIGIN` | 客服站点对外 Origin，如 `https://support.example.com` |
| `COOKIE_SECURE` | 生产设为 `true` |
| `ALLOWED_HOSTS` | 可选，逗号分隔 Host 白名单，如 `support.example.com` |
| `TRUSTED_PROXIES` | 可选，允许信任 `X-Forwarded-*` 的代理 IP/CIDR |
| `FORWARDED_ALLOW_IPS` | Uvicorn 信任的代理跳；应与反代网段一致，勿在公网直暴露时使用 `*` |
| `ADMIN_PASSWORD` / `SESSION_SECRET` / `POSTGRES_PASSWORD` | 使用 `scripts/bootstrap.py` 生成的长随机值 |

## 3. 启动生产向编排

```bash
# 先完成本地 .env，再叠加生产覆盖（仍默认绑定 127.0.0.1，由本机 TLS 反代转发）
docker compose -f compose.yaml -f compose.prod.yaml up -d --build
```

外层 TLS 反代示例见 [deploy/nginx-tls.conf.example](../deploy/nginx-tls.conf.example)：

1. 将 `support.example.com` 换成真实域名。
2. 填入证书与私钥路径（Let's Encrypt 或机构证书）。
3. 把 `frame-ancestors` 写成允许嵌入的官网 Origin。
4. 反代到 `127.0.0.1:${WEB_PORT}`（默认 18080）。

也可由云负载均衡终止 TLS，再转发到内网 `web`；此时同样要设置 `X-Forwarded-Proto` / `X-Forwarded-For`，并把 LB 网段写入 `TRUSTED_PROXIES` 与 `FORWARDED_ALLOW_IPS`。

## 4. 官网嵌入域名白名单

后台 **机器人配置 → 允许嵌入域名**（或 `PATCH /api/admin/settings` 的 `allowed_embed_origins`）维护 Origin 列表，例如：

```text
https://www.example.com
https://example.com
```

规则：

- 创建访客会话时校验 `embed_origin`（组件传入的父页面 Origin）；不在名单内返回 403，并写入审计「拒绝嵌入来源」。
- `PUBLIC_ORIGIN` 始终视为合法（本站独立咨询页 / 工作台预览）。
- 域名白名单与 CORS **不能代替**会话令牌鉴权；令牌仍按会话绑定。

官网页面放入：

```html
<script src="https://support.example.com/widget.js" defer></script>
```

## 5. 后台登录与异常访问

- 写操作校验 `Origin` 必须属于本站 `PUBLIC_ORIGIN`（及本地回环别名）。
- 登录按客户端 IP 限流（10 次 / 5 分钟）；失败与异常来源会记入「操作记录」（`登录失败` / `拒绝异常来源登录`）。
- 公开 widget 接口按 IP / 会话限流；超限返回 429。
- 角色与对象范围权限不变：管理员、知识运营、客服、顾问仍按原边界隔离。

## 6. 验收清单

代码侧可自测：

- 未登录访问 `/api/admin/*` → 401
- 错误 Origin 登录 / 写入 → 403，审计可见
- 连续错误密码 → 429，且有登录失败记录
- 未授权 `embed_origin` 创建会话 → 403
- 顾问越权读取他人线索 → 404/403（既有权限测试）
