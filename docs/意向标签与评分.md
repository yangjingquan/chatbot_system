# 意向标签与评分（第 10 项）

## 定位

规则评分**仅作跟进辅助**，不是成交概率，也不能在缺少机构人工标注样本时宣称真实业务准确率。

- 分类器：`rules`（当前未接模型辅助分类）
- 规则版本：`training-v5`
- 人工改级：线索详情可改等级并锁定；可「恢复自动分级」
- 展示：线索 / 咨询页显示规则分数、置信启发式说明与不确定性提示

## 本轮规则增强

| 场景 | 调整 |
| --- | --- |
| 拒绝联系 | 识别「别打电话 / 不要再打电话 / 停止联系 / 撤回授权」等，标记已停止联系 |
| 否定表达 | 补充「不打算考 X / 事业编不打算考了 / 不想报了 / 没兴趣报名」等 |
| 询价漏判 | 「价格 / 收费 / 费用」计入主动询价；具名考试 + 明确行动至少中意向 |
| 多考试 | 维持分需求记账；部分拒绝不影响另一考试的高等级路径 |
| 售后 | 纯转班/退费/投诉 → 不适用；「投诉之后还想报…」可进入新购信号 |
| 软探索 | 「先不报名，只是问问」保持了解中，不抬高意向 |
| 双重否定 | 「不是不想试听，是想预约…」按正向预约处理，不误取消 |

## 不确定性说明

`confidence` / `uncertainty` 为规则启发式，**未经机构 200–300 条人工标注校准**，不能当作模型置信度或准确率。若以后引入模型辅助分类，须同时展示依据、不确定性，并保留人工修改权。

## 自测

```bash
cd backend && python -m pytest tests/test_scoring.py tests/test_intent_state.py tests/test_review_regressions.py -q
```

合成风险样本覆盖：高意向误判/漏判边界、拒绝联系、售后不误入销售高等级。完整业务准确率仍需机构标注集验收。

## 局限

- 无机构人工标注样本时，不能报告真实准确率、召回率或校准曲线。
- 口语、错别字、方言、截图/语音未覆盖。
- 启发式拒识无法穷尽所有「别再找我」变体。
- 分数与等级变化会随 `rule_version` 升级回填；已人工锁定的等级不会被覆盖。
