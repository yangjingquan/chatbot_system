# 模型费用管理（第 12 项）

## 定位

站内费用为**估算与对账辅助**，以供应商账单为准。未配置单价或未收到用量时显示「未知」，不得当作免费。

## 能力

| 能力 | 说明 |
| --- | --- |
| 单价与预算 | 管理员填写模型名、输入（命中/未命中）、输出单价（元/百万 Token）及日/月预算，并应定期与账单核对 |
| 调用估算 | 仅当模型名匹配且取得 prompt/completion tokens 时写入 `estimated_cny` |
| 未知展示 | 无单价、无用量、模型不匹配 → 费用为 `null` /「未知」，汇总也不会用 ¥0 冒充免费 |
| 用量趋势 | 近 14 日调用、Token、已估价次数与估算费用 |
| 异常增长 | 今日相对近两周有记录日期的 Token/调用明显偏高时提示 |
| 对账辅助 | 已估价 / 未估价 / 未知用量计数与站内已估合计说明 |
| 超预算策略 | 默认仅站内告警；勾选「显式启用超预算降级」后，达日/月预算的新对话改为资料摘录，不调用付费模型 |

## 降级策略（默认关闭）

- `enforce_over_budget=false`（默认）：即使 `daily_alert`/`monthly_alert` 为真，仍可调用模型。
- `enforce_over_budget=true`：管理员显式开启后，对**配置中同名模型**在日或月已估费用达到预算时，新问答降级为 `extractive`，并提示已达预算。
- 未配置单价、用量未知或模型名不一致时，**不会**因「看起来像超预算」而降级。

## 局限

- 估算不含供应商侧未回传用量、失败后仍计费等情形。
- 异常增长为启发式，需人工结合账单判断。
- 降级只影响新的 DeepSeek 调用；已发出的流式回答不会回溯扣减供应商费用。
